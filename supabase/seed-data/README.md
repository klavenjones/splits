# Seed data

Source files for generated migrations. Edit these, regenerate, commit both.

## Built-in exercises

- `exercises.json`: 193 built-ins. Names, muscles and equipment curated from
  [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (Unlicense); instructions are original.
- Each row has a `movement_pattern` (one of the slots in `src/exercises/vocab.ts`).
- Regenerate: `node scripts/build-exercise-seed.mjs` → `migrations/20260929120100_exercise_seed.sql` (unchanged
  since it was pushed) and `migrations/20261008120100_exercise_movement_pattern_data.sql` (tags the slots).

## Built-in illustrations (wger)

- `wger-map.json`: hand-checked map of our exercise name → wger exercise id. Every entry was checked
  visually against the movement. Only Everkinetic / wger.de line art (style 1) qualifies.
- `wger-images.json`: generated by `node scripts/wger-images.mjs`, with the file path and license credit.
- To add or refresh images:
  1. Edit `wger-map.json`, then run `node scripts/wger-images.mjs --download <tmp dir>`.
  2. Look at every downloaded image.
  3. Upload: `npx supabase storage cp -r <tmp dir>/builtin ss:///exercise-media/builtin --linked --experimental --content-type image/png`.
  4. `node scripts/build-exercise-media-migration.mjs` regenerates the migration. For images added
     after it was pushed, write a new migration with the same update statement instead.
